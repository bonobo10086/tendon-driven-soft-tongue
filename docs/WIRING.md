# 实体接线与程序边界

当前使用 Arduino UNO R3、双轴模拟摇杆和 MG90S 位置型舵机。请以实际舵机标签确认电压和线序，不能只凭颜色猜。

| 部件 | 接到哪里 |
|---|---|
| 上舵机信号 | UNO D3 |
| 下舵机信号 | UNO D5 |
| 左舵机信号 | UNO D9 |
| 右舵机信号 | UNO D10 |
| 摇杆 VRx / VRy / SW | UNO A0 / A1 / D2 |
| 摇杆 VCC / GND | UNO 5V / GND |
| 舵机电源正极 | 独立低压电源，经匹配的保险与开关后分线 |
| 舵机电源负极 | 独立电源负极分线组，并与 UNO GND 相连 |
| UNO 供电 | 电脑 USB |

外部动力正极不接 UNO 的 5V、VIN 或圆插孔；舵机动力不经过面包板或普通细杜邦线。正负分线组隔离，每根线使用合适的接线位。

**没有一条“4 个舵机固定用 5 A 保险”的通用规则。** 保险必须匹配负载、导线、开关、端子与直流额定值。现有电源标签上的 5 A 不是已经量得的四舵机电流；本仓库没有最终四路供电验收记录。

## 当前四舵机程序

1. 拔掉动力和 USB，先卸下舵盘侧拉索。
2. 只接 UNO USB，在 Arduino IDE 中上传 `firmware/tongue_controller_final/tongue_controller_final.ino`。
3. 摇杆居中启动，确认动力配置后开启独立电源，手离开机构。
4. 按住摇杆帽约一秒并松开，等待 L 灯常亮。初次启用可能先转向中位。
5. 先空载确认各路收放方向，再安装与中位匹配的舵臂、逐路接索。不能靠换电源极性反转。

默认 `NEUTRAL={90,90,90,90}`，`PULL_DEG` 和 `RELEASE_DEG` 均为 3°；数组顺序是上、下、左、右。每只 `PULL_SIGN` 要按实际安装核对，四只都设 +1 不是几何校准已经完成。

程序包含死区、渐变命令、回中、按键锁定和偏杆约 5 秒的回中锁定。**软件锁定不切断动力，也不检测堵转、张力或过热。** 异常时要立即用可触及的低压开关断开舵机动力。

串口 `115200`，发送 `p` 输出原始摇杆值和角度命令。此版本不接受串口运动指令，不能据此宣称已经支持 ROS 2。打开串口可能让 UNO 重启，不能在未知紧索负载下随意打开。

旧单舵机程序只用于对照，不与四舵机程序同时运行。更完整的原版说明见 [四舵机说明](../firmware/tongue_controller_final/README_CN.md)。

供电依据：[Arduino 官方外部供电与共地说明](https://support.arduino.cc/hc/en-us/articles/360017053760-Troubleshoot-servo-motors)。

# 单舵机首次带载程序

适用：Arduino UNO R3、D3上的一个正常位置型MG90S、五针模拟摇杆。不是四舵机最终程序，不是SOFA的Python场景。不改动原`arduino/tongue_controller/tongue_controller.ino`。

## 接线与上电边界

- 摇杆：VRx→A0，VRy→A1，SW→D2，VCC→UNO 5V，GND→UNO GND。
- MG90S：信号→D3，电源正负→独立且已经检查的5V舵机电源，UNO与舵机电源共地。D5/D9/D10均不接舵机。
- 不经面包板给舵机供动力；保留单舵机2A保险丝、低压总开关和正确极性的母线电容。软件不能代替这些保护。
- 上传、打开串口/复位、接线、安装舵盘、挂索和调线都先关闭舵机动力，并按总操作指南拆除机械张力。第一次上传及空载认方向时不挂舌头拉索。
- 程序开机就向D3发送中位命令，因此“锁定”不等于不输出脉冲、不等于舵机断电，也不能保证上电完全不动。不要带着未知紧索直接开机。

## 使用顺序

1. Arduino IDE打开同目录的`single_servo_load_test.ino`，开发板选Arduino Uno，选实际COM口，验证并上传。
2. 完整接线后上电，摇杆居中约2秒。串口监视器设115200，打开后等待重新校准结束。初次只做无索空载测试。
3. 串口显示`LOCKED`，`pullCommand`和`targetCommand`应回到0。
4. 输入字母`e`，点击发送：允许STEP模式。摇杆不居中、按钮按住或尚未回松时会拒绝启用。
5. 输入一个`+`并发送：仅增加1个“命令角度单位”。先观察空载舵盘孔是否沿收线方向移动。再输入`0`并发送回松锁定。默认最多3个命令单位。
6. 若舵盘孔的运动不是收线方向，断开动力并卸索，将`PULL_DIRECTION`从`1`改为`-1`，重新上传，再做空载测试；不要靠翻接舵机电源改变转向。
7. 实际机械安装、拉力/行程核对通过，且挂索在中位仅消除明显松弛后，才按总指南带载试一次`e`→`+`→`0`。
8. 手动小步测试通过后，在中位发送`e`，再发送`j`进入摇杆模式。正的Y控制收线，摇杆居中或负的Y回松。物理推杆方向以串口Y和实物认定；需要反向时在断电卸索后修改`INVERT_Y`再上传。

## 指令表

| 指令 | 作用 |
|---|---|
| `e` | 在中位且摇杆居中时启用，进入STEP模式 |
| `+` | STEP模式目标收线增加1个命令单位，上限为`MAX_PULL_DEG` |
| `-` | STEP模式目标收线减少1个命令单位，下限为0 |
| `0` | 平缓回到中位，锁定；要继续需重新发送`e` |
| `j` | 中位切换到单向摇杆控制；另一半摇杆行程只回松，不反向收线 |
| `m` | 切回STEP，保持当时命令；`0`仍可回松 |
| `p` | 立即显示状态 |
| `?` | 显示帮助 |
| 按下摇杆 | 回松锁定，不切换自动模式 |

回车/换行会忽略。没有自动往复功能；不要按旧教程把摇杆按钮当AUTO开关。

每次只输入一个字符并点击发送，观察动作后再发下一个。不要把`e+0`作为一整串同时发送，否则程序可能在实际运动前就收到回松命令；`0`是数字零，不是字母O。

## 5秒保护不是“卡住”

从开始收线到完全回松，若持续存在非零收线命令达到5秒，程序开始平缓回松并锁定。此后即使摇杆仍推着也不会自动恢复。先松杆，等`pullCommand=0`，再发送`e`。若想继续摇杆模式，再发送`j`。

它不是力、温度或堵转检测；出现锚板移位、舌体不动而舵机发响、裂口或明显发热，立即用低压总开关切断动力，不等待5秒，也不要只依靠软件按钮。

## 这些数字不是实测值

`MAX_PULL_DEG=3.0f`是首次带载保守的软件命令范围，不是3mm舌尖位移，也不是保证实际舵机转3°。`shaftCommand`仅由程序计算；MG90S没有向此程序提供轴角或力反馈。

不因动作很小就直接放大到30°、90°或180°。增大范围前，必须验证完整样件拉力、真实收线行程、舵盘运动方向、对侧放松及回中。修改限位和重新上传同样要断开动力并卸索。
